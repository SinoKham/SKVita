# HealthyBot

Backend-сервис для отслеживания здоровых привычек. 
Версия 0.3 - консольная версия + FastAPI

## О проекте

HealthyBot помогает вести дневник питания, сна, воды, 
физической активности и настроения. Проект создаётся как 
pet-project backend-разработки: от ООП 
до FastAPI, PostgreSQL и Telegram-бота.

Цель - записывать данные и находить 
статистические закономерности между привычками 
(например, как сон влияет на активность и настроение). Также улучшить навыки в программировании, самостоятельно создать полноценное backend-приложение на Python

## Запуск

Требуется Python 3.12 (проверено на 3.12.0)

- Консольная версия
```bash
python -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m app.main
```

- API сервер
```bash
uvicorn app.api:app --reload
```
После запуска API открывается на http://127.0.0.1:8000, 
документация — на http://127.0.0.1:8000/docs.

## Возможности

### Консольная версия (v0.1–v0.2)

- Создание профиля пользователя
- Добавление приёмов пищи с расчётом калорий и БЖУ
- Запись сессий сна с автоматическим расчётом длительности
- Учёт выпитой воды
- Учёт физической активности с автоматическим расчётом сожжённых калорий по количеству шагов
- Запись настроения с заметками
- Просмотр общей статистики по дневнику

### API (v0.3)

- GET / статус
- POST /foods  создать продукт
- GET /foods список
- GET /foods/{id} продукт по id
